BACKGROUND

教会オルガニストが66歳で書いた、最初で最後の交響曲

セザール・フランク(1822–1890)はベルギー・リエージュ生まれ。パリ音楽院でピアノを学んだのち、生涯の大半を教会オルガニストとして過ごしました。1858年にサント=クロチルド教会の主任オルガニストに就任し、1872年からはパリ音楽院オルガン科教授も務めています。弟子にはヴァンサン・ダンディ、エルネスト・ショーソン、アンリ・デュパルク、ルイ・ヴィエルヌ、シャルル・トゥルヌミール、ギヨーム・ルクーら——後に「フランキスト」と呼ばれる一群がいました。代表作(この交響曲・ヴァイオリンソナタ・弦楽四重奏曲)はいずれも驚くほど晩年に集中して生まれています。

交響曲の作曲は1887年の夏に始まり、総譜が完成したのは1888年8月22日、フランク66歳のときでした。献呈されたのは、ワーグナーの楽劇研究を勧めた弟子デュパルクです。初演の道のりは平坦ではなく、指揮者シャルル・ラムルーには一度断られています。結局1889年2月17日、パリ音楽院のコンセール・ソシエテで、ジュール・ガルサン指揮により初演されました。フランクはその翌1890年、乗合馬車との接触事故をきっかけに体調を崩し、この世を去ります。

初演の評価は真っ二つでした。『フィガロ』紙は「きわめて重要な作品」としつつ「あまりに濃密で緊密なため、一度聴いただけではその全貌を掴みきれない」と書き、熱狂と冷淡さの同居を伝えています。批評家カミーユ・ベレーグは「潤いも魅力もない、乾いてくすんだ音楽」と切り捨て、『ル・メネストレル』紙は「陰鬱で仰々しく、語ることが少ない」と評しました。作曲家グノーに至っては「独断にまで押し進められた無能の断言」と言い放ったと伝えられます。とりわけ集中砲火を浴びたのが、第2楽章で主題を歌うコーラングレ(イングリッシュホルン)でした——音楽院の同僚が「交響曲にコーラングレを使うなど、誰が聞いたことがあるか」と詰め寄った逸話は有名です。普仏戦争(1870–71)の敗戦後、フランス音楽界にはナショナリズムが渦巻いており、ワーグナーとリストの影響を隠さないフランクの書法は「裏切り」とすら見なされました。

それでも作曲者自身は動じませんでした。弟子たちが伝えるところによれば、フランクは初演のホールを出るとき「実によく鳴ったじゃないか」と満足げに語ったといいます。作品が広く受け入れられたのは、1893年に当のラムルーがようやく取り上げてからのこと。以後この曲は、フランスの交響曲としては例外的な頻度で演奏される「近代の古典」となりました。

フランク自身は3つの楽章にそれぞれ性格づけを与えています——第1楽章は「力強く、そして温かく」、第2楽章は「甘美で、もの悲しく」、終楽章は「輝かしく、光を放つように」。第2楽章が緩徐楽章とスケルツォを1つに融合した特異な構造なのは、4楽章制を3楽章に圧縮した結果です。そして全体を貫くのが循環形式(cyclic form)——冒頭に置かれた短い動機が、姿を変えながら全楽章に回帰する構成原理です。ベートーヴェンの第9交響曲を先例とし、直接には前年に成功したサン=サーンス《オルガン付き》交響曲(1886)からの示唆があったとされます。

今回参照した楽譜について — なぜ小節番号が旧版と違うのか

この交響曲の自筆総譜は1935年、シャトーの火災で焼失しています。そのため現行の校訂譜は、フランク生前に出版された初版譜と、作曲者自身による4手ピアノ編曲を典拠に復元されたものです。今回参照したブライトコプフ&ヘルテル社のウアテクスト版(Peter Jost 校訂, 1999年 / Orchester-Bibliothek 5328)もこの系譜にあります。
このパート譜には各段の頭に小節番号が、そして練習記号(A, B, C…)が明記されています。本ロードマップの小節番号・練習記号はすべてこの版の印刷値です。IMSLPで入手できるパブリックドメインの旧パート譜とは番号がずれる箇所があるため、他パートの奏者と場所を確認し合うときは「どの版か」を先に揃えてください。

OVERVIEW

なぜこの曲の第1ヴァイオリンは難しいのか

この曲の第1ヴァイオリンに求められるものは、はっきりしています——①加線4本の高音を ff で「入る」のではなく「叩き込む」度胸、②16小節を音色を保ったまま歌い切るスタミナ、③長い休みをキュー音符だけを頼りに数え切る集中力、そして④循環主題を「弾く側」と「聴く側」に切り替える判断です。

音域の数字がそれを物語ります。第1楽章の最高音は a‴(加線4本の上)で、そこへ ff で跳び込む場面が2度(m.33 / m.81)。第3楽章でも m.37 で A6 に達します。一方で ff sostenuto の主旋律を16小節連続で歌う場面が2度(第1楽章 m.129–144 / m.419–434)あり、楽章前半で力を使い切ると再現部で音色が保てません。この配分こそが、この曲の1stヴァイオリンの本質的な課題です。

意外なのは第2楽章です。冒頭から m.47 までは第1ポジションのみのピチカート伴奏——コーラングレとハープに場所を譲り、完全に裏方に回ります。ところが C(m.48)で猶予1拍の pizz.→arco を挟んだ途端、m.49 から dolce cantabile の主旋律が始まる。楽章で最も音楽的に重要な入りが、最も慌ただしい切替の直後に置かれている——この設計を知っているかどうかで、本番の安心感がまったく変わります。

そして冒頭の Lento で1stヴァイオリンは休みです。循環主題を最初に鳴らすのはヴィオラ・チェロ・コントラバスで、1stVn の譜面にはそれが「Va.」のキュー音符として印刷されています。まずこのキュー音符を歌えるようにすることが、この曲の出発点になります。

以下の楽章別セクションは、パート譜全15ページ(第1楽章 p.2–7 / 第2楽章 p.8–11 / 第3楽章 p.12–16)を1ページずつ視覚解析し、印刷された小節番号・練習記号・強弱・奏法指示をすべて拾い出したうえで構成しています。

ROADMAP

本番までの6フェーズ

4〜6ヶ月以上という期間を想定した段階分けです。期間が4ヶ月に近い場合はフェーズ5・6を圧縮して並行させ、6ヶ月以上あるならフェーズ2・3を長めに取ってください。「何ヶ月目か」より「どの段階の課題を今やっているか」を意識するのが大切です。

  1. 1

    全体像の把握と、循環主題を耳に入れる 目安: 1ヶ月目

    曲の地図を頭に入れ、指と身体に音を通す段階。

    • まず循環主題を歌えるようにする。第1楽章 m.1–5 は自分は休みですが、パート譜に「Va.」のキュー音符として主題が印刷されています。ここから始めてください。
    • 全曲を通して1回、遅いテンポで初見通し。止まらず最後まで、を優先。
    • 総譜スクロール付きの音源(後述)で全曲を追い、自分が休んでいる長い区間で何が鳴っているかを確認する。とくに第1楽章の m.183–190・m.298–306・m.465–472 と、第3楽章の m.98–109。
    • ニ短調・ヘ短調・変ロ短調・ニ長調のスケールとアルペジオを毎日のウォームアップに。第1楽章 m.349 の♭6つ(変ホ短調)と第2楽章 m.222 の♯5つは別に練習を。
    • 高音域の「地図」を作る。a‴(第1楽章 m.33・m.81)、A6(第3楽章 m.37)、G6(第3楽章 m.190・m.201)——この4つの最高音に到達する運指を、最初に決めて書き込んでしまう。
  2. 2

    難所の分解練習 目安: 2ヶ月目

    各楽章の難所を、メトロノームで個別に潰していく段階。

    • 第1楽章: m.33–38 と m.81–86 は同じ音型の移調なので必ずセットで。まずリズムを外して骨格音だけをゆっくり弾き、a‴ からの下降ポジションを目で覚える。
    • 第2楽章: pizz.⇄arco を単独ドリル化。m.48(猶予1拍)と m.188(猶予1.5拍、pizz.は3音だけ)を集中的に。弓を持ったまま人差し指で弾く方式に統一するかを、ここで決めてしまう。
    • 第3楽章: m.300–307 の16分音符8小節を、まず「2/2の1拍＝3/4の1拍」の確認から。m.262–267 のオクターヴ重音3連符は上声・下声を別々に暗譜。
    • 弱音器は本番と同じ器具で着脱時間を体に覚えさせる。第2楽章 m.238 の猶予は約6拍で、外した直後が f espress. です。
    • 長い持続音(第1楽章 m.99–106 / m.389–396 / m.473–484)の弓の配分を決め、返す小節に印を付ける。
  3. 3

    歌い切るスタミナと、テンポアップ 目安: 3ヶ月目

    「弾ける」から「16小節持たせる」へ移る段階。

    • ff sostenuto の16小節(第1楽章 m.129–144 / m.419–434)を通しで練習する。弓配分表を作り、隣と統一する。
    • 力の配分を設計する。m.419–434 で音色が保てなくなるなら、原因は m.99–128 にあります——ここを意図的に力を抜いて弾くことで再現部の余力を作る。
    • 第3楽章 m.419–431 の13小節 ff も同様に、「4小節ごとに肩を落とす」ポイントを譜面に書き込む。
    • 本番に近いテンポで通し、崩れた箇所はフェーズ2の分解練習に戻す(往復してよい)。
  4. 4

    パート内合わせと、キュー音符の暗譜 目安: 4ヶ月目

    セクションで音を揃え、長い休みを「聴いて入れる」ようにする段階。

    • キュー音符を実際に歌えるようにする。第1楽章 m.191 の「Vl. II」(9小節休み+フェルマータ3つの後)、m.305–306 の「Vl. II」(9小節休みの直前2小節)、m.469–472 の「Kl. I」。フェルマータがある区間は拍で数えられないので、キューが唯一の手がかりです。
    • 重音の運指を統一する。第1楽章は m.47・m.127・m.417 の3か所だけ(div. の指示はなく全員が重音)。第3楽章 m.262–267 のオクターヴ重音は分奏するかどうかを指揮者・コンマスに早めに確認を。
    • ボウイングの統一。とくに循環主題の付点リズム(第1楽章 m.29ほか)と、第3楽章 m.300–307 の「1拍＝1弓」。
    • 練習記号を区切りにして部分練習できるようにする。Jは欠番(Iの次はK)なので注意。
  5. 5

    オーケストラ合わせとスタミナ強化 目安: 5ヶ月目

    全奏の中でのバランスと、全曲を通す体力をつける段階。

    • 合奏では、自分が主題を弾いているのか、対旋律なのか、走句で推進しているのかを常に判別する。第1楽章 m.213(I)の "f ma cantando" は速い下行を機械的でなく歌わせる場面です。
    • 循環主題を自分が弾く5か所(第1楽章 m.29 / m.77 / m.199 / m.349 / m.362)を、ヴィオラ・チェロ・コントラバスの提示と聴き比べて性格を揃える。
    • 3楽章を止まらずに通す練習を重ね、第3楽章 m.419–431 の13小節 ff まで体力を持たせる。
    • テンポの伸縮への反応練習——第2楽章 F のテンポ変化5回、第3楽章 m.227 の "très long" フェルマータ、m.339–345 の rall. 中の7小節休み。
  6. 6

    仕上げ・本番直前調整 目安: 6ヶ月目／最終週

    技術的な伸びしろより、再現性とコンディションを整える段階。

    • 新しい練習は増やさず、難所を短時間・高頻度で確認するメンテナンス練習に切り替える。
    • 疲労した状態での難所練習を最後に一度——第1楽章コーダ(m.501–512)と第3楽章コーダ(m.419–440)は、体力が尽きた状態で来ます。
    • ゲネプロで指揮者を見る余裕(目線配分)が確保できているか確認する。とくにフェルマータの多い区間。
    • 楽器・弓・弱音器・松脂など本番当日の道具一式を、直前リハーサルで実際に使っておく。
MOVEMENT I

第1楽章 — Lento / Allegro non troppo

ニ短調 / 4-4 ⇄ 2-2 / 全521小節
練習記号 A〜V(Jは欠番・全21個)

1stヴァイオリンにとってこの楽章は、全曲で最も音域が高く、最も長く歌い続ける楽章です。最高音は a‴(加線4本の上) で、そこへ「入る」のではなく ff で叩き込む場面が2度あります(m.33 / m.81)。さらに m.129 からは ff sostenuto の主旋律を16小節連続で歌い切り、再現部の m.419 でもう一度同じことを要求されます。循環主題を主旋律として弾くのは5か所——冒頭の Lento は休みで、ヴィオラのキュー音符として主題が印刷されています。

「4声の和音」に見える記号は、和音ではなくトレモロです

Lento部分(m.17–28 / 65–76 / 331–348 / 519–521)に見える「4声の和音のような記号」は、拡大して確認したところ符幹に3本線を付したトレモロ記号でした。したがってこれらは単音のトレモロであり、重音ではありません。この楽章で実際の重音は m.47・m.127・m.417 の3か所だけです。
また、1stVn譜には第1楽章を通じて div. の指示がありません(2ndVn譜には m.17 以降に div. トレモロがあります)。上下どちらを弾くかの判断は不要で、重音3か所も全員が重音で弾く読みになります——運指は事前にパート内で統一してください。

  1. 1

    m.113–123(G〜H) / m.180–183 — 弱音器付き pp の連続半音階16分 切れ目のない16分音符が11小節続きます。con sordino・pp・低音域(G線〜D線)という条件で、弓は弦から離せないのに音量は出せないという相反する要求。♯♮♭が入り乱れる半音階で、低いポジションの狭い指の間隔が崩れやすい。しかも弱音器を付けると楽器からのフィードバックが減り、自分の音程が聞こえにくくなります。 対策: ①リズム変奏(付点／逆付点／3連グルーピング)を各小節10回ずつ。②音程の骨格取り——16分を4つずつ止めて各拍の頭の音だけを抜き出し、開放弦と照合してから中の音を埋める。③弓の設定を固定——上半弓・弓幅3〜5cm・接触点は指板寄り。♩=60から「弓を小さくしても音が消えない最小限の圧」を探す。この練習は必ず弱音器を付けた状態で行うこと(付けない練習では意味が薄い)。④弱音器あり／なしの交互練習で音色差を耳に入れる。

  2. 2

    m.96–112(F) — sempre pp の極高音と、テンポ変化5回 m.102–104が加線3本前後の極高音で、しかも pp・弱音器付き。E線の第7〜9ポジションで弱い弓圧のまま音を出すのは物理的に最も難しい条件です——圧が足りないと鳴らず、多いと潰れる。さらに 7小節の間に poco rall. と a tempo が5回入れ替わり、その大半が休符とフェルマータの中で起こります。 対策: ①高音の「着地」練習——m.102の3連符の最初の音だけを、下のポジションから音を出さずに移動してから弓を置く順序で20回。移動と発音を分離します。②弱音器を付けたままE線で「pp のロングトーンを弓を止めず減衰させずに保つ」を各ポジションで(指板寄り・弓速やや速め・圧最小)。③休符に指揮者の拍と rall./a tempo の位置を鉛筆で図示する。フェルマータ(m.100・m.104)は誰が伸ばしているかを総譜で確認しておくこと——パート譜では判断できません。

  3. 3

    m.187–188 / m.48 / m.86 — pizz.⇄arco の超短時間の切替 m.187–188 の pizz. はわずか3音。そのために弓を持ち替え、1.5拍で arco に戻って pp の3連符を弾き始めます。m.48 は逆に、pizz.の直後4分休符1拍だけで持ち替えて、いきなり dolce cantabile の主旋律のアウフタクト——音楽的にいちばん大事な入りが、最も慌ただしい切替の直後にあります。 対策: ①持ち替えの型を箇所ごとに決める——pizz.が短い m.187–188 は弓を持ったまま人差し指で弾く一択(弓を手のひらに収める動作は入れない)。逆に m.86–94 の長い pizz. 区間は標準の持ち方でよい。同じパートでも箇所によって方式を変えることを、あらかじめ決めておくのが要点です。②メトロノーム♩=72で「1小節→切替→次の1音」を20回、音楽を弾かず動作だけを身体に入れる。③m.48は「pizz.の音を短く切る→休符の頭で弓を弦上にセット→3拍目は弓の中央から」の3ステップに固定し、弓を弦に置いた状態で1拍待つ余裕を作る。

第3楽章の難所トップ7

  1. 1

    m.262–267(N) — ff オクターヴ重音の連続3連符 4分音符の3連符(1小節6音)が6小節間ほぼ切れ目なく、しかもすべてオクターヴ重音。上声は加線1〜3本、下声は五線上部。ff で押し切ろうとすると重音のピッチが開き、右手も潰れます。半音階的に動くため同じ形の反復ができません。 対策: ①まず上声のみを正しい運指・ポジションで暗譜レベルに。②次に下声のみ。③重音は「1の指と4の指の枠」を固定し、移弦せず同一弦ペア(A–E線)で保つ運指を先に決める。④♩=半分から、各3連符の頭だけを止めてピッチを確認するストップ練習。⑤弓は元弓寄りの短めのデタシェで、1小節6音を「上げ・下げ×3」で均等配分。⑥どうしても崩れる場合はプルト内で上下に分ける判断を指揮者・コンマスに早期に確認しておく。

  2. 2

    m.300–307 — 3/4への変拍子直後の ff sempre 16分音符 m.300 でいきなり 2/2→3/4 に切り替わり、「拍の長さは変わらない」＝2分音符1拍が4分音符1拍になるため体内テンポの再設定が要ります。そこへ1小節12個の16分音符が8小節間途切れず、順次進行と分散和音が混在して弦跨ぎが頻発、臨時記号も多い。 対策: ①まず O(m.296)から m.300 への移行だけを取り出し、「2/2の1拍＝3/4の1拍」をメトロノームで確認する(3/4側は3拍ずつ鳴らす)。②16分はリズム変奏(付点／逆付点／3+1／1+3)で。③移弦箇所に鉛筆で印を付け、右肘の高さを事前に決める。④スラーは各拍1本なので、1拍＝1弓の弓量を固定して腕の高さだけで移弦する。⑤テンポは最終テンポの60%から5刻みで。

    m.36–41 / m.187–197(I) / m.198–202 — 最高音域での ff m.37 で F♯6 → A6(加線4本の上)に跳び、m.190 では G6、m.201 でも G6 付近。ff のマルカート付きで、E線の7〜10ポジション以上を跳躍で当てに行く必要があります。高いポジションほど駒寄りに寄せないと音が鳴らず、寄せすぎると潰れる。 対策: ①各高音の着地ポジションを1つに決めて書き込む(m.37のA6＝E線9〜10ポジションの1の指、など)。②その音単独で開放E→目標音のグリッサンド練習で「距離感」を体に入れる。③到達したら駒との距離・弓速・圧の3点セットを決めて固定。④m.187–197はマルカートが付くので弓の頭を作る(弓を弦に置いてから引く)練習を pp で行い、その後 ff に拡大する。

MUSIC THEORY BRIDGE

お手元の音楽理論資料との橋渡し

お手元の理論資料(「最短ルートで学ぶ音楽理論の基礎の基礎」)は、スケール・度数・ダイアトニックコード・進行というポップス寄りの基礎体系です。フランクの和声はこの基礎の延長線上にありながら、意図的にそこから「はみ出す」ことで独特の緊張感を作っています。実際の練習で役立つ橋渡しを4点にまとめます。

持続和音では「自分が何度の音か」を意識する

第1ヴァイオリンは長い和音を保持する場面こそ少ないものの、第1楽章 m.99–106・m.389–396・m.473–484 のように8〜12小節の持続音で和声の一員になる場面があります。資料の「度数」の考え方(長3度・短3度・完全5度…)で、自分の音が根音から見て3度なのか5度なのかを意識すると、単なる「ハモり」ではなく機能的なチューニングができます。長3度は理論値よりわずかに低め、短3度はわずかに高めに取ると和声が澄みます。

フランクの和声は「ダイアトニックの外側」を多用する

資料にある「スケール上で使える和音(Ⅰ・Ⅱm・Ⅲm・Ⅳ・Ⅴ・Ⅵm・Ⅶdim)」はポップスの基本ですが、フランクはⅦdim(減7の和音)や半音による転調を頻繁に使います。終楽章 m.162–186 の25小節にわたる半音階的な8分音符などは、まさに「ダイアトニックを外れ続ける」書法。こうした箇所の音程は、機能和声のロジックではなく「隣の音との半音／全音関係」を頼りにした方が安全です。

循環形式 = 主題の「移調・変容」

資料の「キーチェンジ(全ての音を同じ半音数だけズラす)」の考え方は、循環主題がニ短調のLentoから始まり、終楽章でニ長調へと移調・変容していく様子を理解する助けになります。同じ主題が違う調・速度で出てきたときに「これはあの主題の変形だ」と気づけるようになると、暗譜的な安心感が格段に上がります。終楽章では調号が2度切り替わる(♯2→♯5→♯2)ことも、この変容の道筋を示す手がかりです。

和声語法の「タイプ」を意識する — フランクの"breaking points"論

音楽学者ニコラ・コマトヴィッチの論文「Franck's Breaking Points」は、フランクの和声語法を大きく3タイプ(Type 1=初期の素朴なディアトニック和声、Type 1A=モーダルな要素を含む変種、Type 2=半音階的だが機能和声の骨格はまだ残る円熟期の基本語法、Type 3=機能和声そのものが崩壊し調性判定が困難な晩年のオルガン曲)に整理し、同じ曲の中でもこれらのタイプが急に切り替わる瞬間があると指摘しています。この交響曲では第1・第3楽章がほぼType 2である一方、第2楽章は両端の楽章と比べて和声的にずっと平明だと論文は述べています——「第2楽章は親しみやすい」という肌感覚を、和声語法の面から裏付ける知見です。第1ヴァイオリンは主旋律を担う立場ですが、その旋律が乗っている和声がどのタイプかを意識すると、いま支えているのが半音階的な緊張なのか、素朴で安定した和声なのかを意識すると、音程の作り方(半音階部分は隣接音との関係を優先、機能和声部分は根音基準の度数を優先)を自然に切り替えられます。

なお、同論文の譜例(第3楽章 mm.19–22、ピアノ編曲譜)の説明は、要約版と同じ著者の詳細論文(Komatović, "Evolution Through Synchronicity?", 2022)との間で食い違いがあります——要約版は「表面上は嬰ヘ長調でありながらロ(B)を中心としたミクソリディア旋法への小旅行」、詳細版は「嬰ヘ短調の和音が下属和音の第3音を上げて長和音化し、一時的に嬰系のドリア旋法へ転じる」とし、旋法の種類も調性も一致していません。演奏の指針というより、専門家の間でも解釈が割れる複雑な書法であることを示す背景知識として捉えてください。

GLOSSARY

用語集 — パート譜とこのロードマップに登場する用語

パート譜に実際に印刷されている指示と、このロードマップ中で使った専門用語を、演奏上の意味とともにまとめました。

テンポ・曲想

Lento

「ゆっくりと」。第1楽章冒頭や循環主題が静かに回帰する場面で使われる、この曲の「原点」の速度。

Allegro non troppo

「快速に、ただし度を越さずに」。第1・第3楽章の基本テンポ。「速いが走りすぎない」という抑制が求められる。

Allegretto

「やや快速に」。第2楽章の基本テンポ。Allegroよりやや控えめな快活さ。

Tempo I.

「最初のテンポで」。テンポが大きく動いたあと、楽章冒頭の速度に戻る指示。第3楽章 m.228 に登場する。

Più lento

「より遅く」。フェルマータや静寂部の直前など、テンポが一段緩む箇所に登場する。

a tempo

「もとの速さに戻って」。テンポの伸縮のあとに元のテンポへ復帰する指示。

rallentando (rall.) / poco a poco rall.

「だんだん遅く」／「少しずつ、だんだん遅く」。第3楽章 m.341 の poco a poco rall. は、5小節の休符と重なるため特に注意が要る。

sostenuto / molto sostenuto

「音を十分に保って」／「たっぷりと保って」。音価いっぱいまで途切れさせずに保持するニュアンス。

très long

フランス語で「非常に長く」。第3楽章 m.226–227 のフェルマータに付され、楽章最大の「間」を作る。

Les temps ont la même valeur

フランス語で「拍の長さは同じ」。拍子が変わっても1拍の実時間は変わらないことを示す指示。第3楽章の4か所の拍子変換にすべて付いている。

cantabile / dolce / espressivo

「歌うように」／「甘く柔らかに」／「表情豊かに」。いずれも音量ではなく、フレーズの歌わせ方を指定する曲想語。

sempre〜

「常に〜」。既存の指示をそのまま継続・強調する(sempre ff=ずっと ff のまま、など)。

強弱記号

pp / ppp

「非常に弱く」／「極めて弱く」。この曲では ppp が頻出し、ディヴィジや重音と組み合わさるため単に小さく弾くだけでは足りない。

f / ff

「強く」／「非常に強く」。段階が上がるほど、音量以上に弓の重心とスピードのコントロールが要求される。

cresc. / dim.

crescendo=「だんだん強く」、diminuendo=「だんだん弱く」。molto cresc.は「大きくクレッシェンド」。

sf / sfz (sforzando)

「その音だけ特に強く」。前後の強弱の流れとは別に、単発でアクセントのように打ち込む指示。

marcato ( ^ )

「はっきりと際立たせて」。音符の上の山形記号。一音一音の輪郭を明確に打ち込む。

奏法・技術用語

pizzicato (pizz.) / arco

pizzicato=弓を使わず指で弦をはじく奏法。arco=通常の弓奏に戻る指示。第2楽章はこの切替が頻発する。

divisi (div.) / unisono (unis.)

div.=パート内で複数のグループに分かれて別々の音を弾く指定。unis.=全員が同じ音に戻る指定。誰が上声・下声を弾くかを事前に決めておく必要がある。

double corde

フランス語で「重音」。ディヴィジとは異なり、奏者ひとりひとりが2音を同時に鳴らす指定。第3楽章 m.360 に登場。勝手に分けると和音が痩せる。

4e corde(G線指定)

フランス語で「第4弦」。最低音のG線だけを使って弾く指定。ポジション移動が増える代わりに、暗く太い独特の音色が得られる。第3楽章 m.330 に登場。

トレモロ (trem.)

符尾に斜線を付けて示す、同じ音を細かく速く反復する奏法。第3楽章の刻みの大半がこれ。斜線の本数で細分の単位が決まる。

弱音器 (con sordino / senza sordino)

駒に取り付けて音色をまろやかに変える器具(ミュート)。con=装着、senza=解除。第2楽章で着脱が頻発する。

ペダル音(保続音)

和声が変化していく間、同じ音を長く保持し続ける低音・内声のこと。第3楽章 m.228以降の半音下行する全音符群が典型。

détaché / legato / スタッカート

détaché=1音ごとに弓を返す奏法。legato=複数音を1弓で滑らかにつなぐ。スタッカート=音を短く切る。ボウイング統一の際に区別が問題になる。

三連符

1拍を3等分して弾くリズム単位。第3楽章 m.257–267 では4分音符の3連符が重音で連続し、この曲有数の難所を作る。

プルト

2人1組で1つの譜面台を共有する単位。ディヴィジの割り振りは通常このプルト単位(前プルト＝上声／後プルト＝下声)で決める。

形式・構造用語

ソナタ形式

提示部・展開部・再現部からなる、古典派〜ロマン派の楽章で最も一般的な大規模構成。第1楽章がこれにあたる。

提示部 / 展開部 / 再現部 / コーダ

ソナタ形式を構成する各部分。提示部=主題の初出、展開部=主題の分裂・変容、再現部=主題の回帰、コーダ=曲を締めくくる結尾部。

循環形式

冒頭で提示される主題(モットー)が姿を変えながら全楽章を貫いて回帰する構成。この曲全体を貫く最重要のキーワード。

練習記号(リハーサルレター)

スコアとパート譜に印刷された太字の大文字(A, B, C…)。合奏で指揮者が最も頻繁に使う箇所指示の単位。慣例として I の次は J を飛ばして K になる(I と J の混同を避けるため)。
