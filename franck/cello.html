BACKGROUND

教会オルガニストが66歳で書いた、最初で最後の交響曲

セザール・フランク(1822–1890)はベルギー・リエージュ生まれ。パリ音楽院でピアノを学んだのち、生涯の大半を教会オルガニストとして過ごしました。1858年にサント=クロチルド教会の主任オルガニストに就任し、1872年からはパリ音楽院オルガン科教授も務めています。弟子にはヴァンサン・ダンディ、エルネスト・ショーソン、アンリ・デュパルク、ルイ・ヴィエルヌ、シャルル・トゥルヌミール、ギヨーム・ルクーら——後に「フランキスト」と呼ばれる一群がいました。代表作(この交響曲・ヴァイオリンソナタ・弦楽四重奏曲)はいずれも驚くほど晩年に集中して生まれています。

交響曲の作曲は1887年の夏に始まり、総譜が完成したのは1888年8月22日、フランク66歳のときでした。献呈されたのは、ワーグナーの楽劇研究を勧めた弟子デュパルクです。初演の道のりは平坦ではなく、指揮者シャルル・ラムルーには一度断られています。結局1889年2月17日、パリ音楽院のコンセール・ソシエテで、ジュール・ガルサン指揮により初演されました。フランクはその翌1890年、乗合馬車との接触事故をきっかけに体調を崩し、この世を去ります。

初演の評価は真っ二つでした。『フィガロ』紙は「きわめて重要な作品」としつつ「あまりに濃密で緊密なため、一度聴いただけではその全貌を掴みきれない」と書き、熱狂と冷淡さの同居を伝えています。批評家カミーユ・ベレーグは「潤いも魅力もない、乾いてくすんだ音楽」と切り捨て、『ル・メネストレル』紙は「陰鬱で仰々しく、語ることが少ない」と評しました。作曲家グノーに至っては「独断にまで押し進められた無能の断言」と言い放ったと伝えられます。とりわけ集中砲火を浴びたのが、第2楽章で主題を歌うコーラングレ(イングリッシュホルン)でした——音楽院の同僚が「交響曲にコーラングレを使うなど、誰が聞いたことがあるか」と詰め寄った逸話は有名です。普仏戦争(1870–71)の敗戦後、フランス音楽界にはナショナリズムが渦巻いており、ワーグナーとリストの影響を隠さないフランクの書法は「裏切り」とすら見なされました。

それでも作曲者自身は動じませんでした。弟子たちが伝えるところによれば、フランクは初演のホールを出るとき「実によく鳴ったじゃないか」と満足げに語ったといいます。作品が広く受け入れられたのは、1893年に当のラムルーがようやく取り上げてからのこと。以後この曲は、フランスの交響曲としては例外的な頻度で演奏される「近代の古典」となりました。

フランク自身は3つの楽章にそれぞれ性格づけを与えています——第1楽章は「力強く、そして温かく」、第2楽章は「甘美で、もの悲しく」、終楽章は「輝かしく、光を放つように」。第2楽章が緩徐楽章とスケルツォを1つに融合した特異な構造なのは、4楽章制を3楽章に圧縮した結果です。そして全体を貫くのが循環形式(cyclic form)——冒頭に置かれた短い動機が、姿を変えながら全楽章に回帰する構成原理です。ベートーヴェンの第9交響曲を先例とし、直接には前年に成功したサン=サーンス《オルガン付き》交響曲(1886)からの示唆があったとされます。

今回参照した楽譜について — なぜ小節番号が旧版と違うのか

この交響曲の自筆総譜は1935年、シャトーの火災で焼失しています。そのため現行の校訂譜は、フランク生前に出版された初版譜と、作曲者自身による4手ピアノ編曲を典拠に復元されたものです。今回参照したブライトコプフ&ヘルテル社のウアテクスト版(Peter Jost 校訂, 1999年 / Orchester-Bibliothek 5328)もこの系譜にあります。
このパート譜には各段の頭に小節番号が、そして練習記号(A, B, C…)が明記されています。本ロードマップの小節番号・練習記号はすべてこの版の印刷値です。IMSLPで入手できるパブリックドメインの旧パート譜とは番号がずれる箇所があるため、他パートの奏者と場所を確認し合うときは「どの版か」を先に揃えてください。

OVERVIEW

なぜこの曲のチェロは難しいのか

チェロには全曲でいちばん重い責任があります——m.1 の1拍目、循環主題を最初に鳴らすのがチェロだからです(ヴィオラ・コントラバスと共に)。パート譜の冒頭に休符ではなく実音(d–cis–f)が p で書かれている。冷えた状態の1音目で、オーケストラ全体の音程が決まります。しかもこの主題を第1楽章だけで6回弾く——4パート中で最多です。

技術の山は別のところにあります。第1楽章 m.417–434 の18小節ノンストップの8分音符——低音↔高音の交替型で弦跨ぎが1拍ごとに発生し、実質128音以上を ff で弾き続けます。後半は音程よりも弓が持たなくなることで崩れる。そして♭6の調号のまま加線3〜4本を読む m.349–358。

音部記号の扱いも独特です。第1楽章ではヘ音⇄テノールを4区間往復し、m.65 と m.321 は小節の途中で切り替わります。ところが第3楽章は全440小節がヘ音記号のみ——テノール記号もト音記号も1か所も現れません。その代償として、G4〜A4 相当の高音もすべてヘ音記号の加線3〜4本で書かれています。該当箇所に鉛筆でテノール記号を書き足すだけで、読譜負荷が半減します。

第2楽章は4パート中で最も奏法の切替が多い楽章です。pizz.⇄arco が20回——うち猶予が0.5拍しかない切替が5回、とくに m.199 は1小節の中に「arco → pizz. → arco」と3つの奏法指示が並記されています。「弓を持ったまま人差し指で撥弦する」方式を全区間の標準にする——この方針を最初に決めることが、この楽章の攻略法です。

以下の楽章別セクションは、パート譜全15ページ(第1楽章 p.1–7 / 第2楽章 p.8–10 / 第3楽章 p.11–15)を1ページずつ視覚解析し、印刷された小節番号・練習記号・強弱・奏法指示をすべて拾い出したうえで構成しています。

ROADMAP

本番までの6フェーズ

4〜6ヶ月以上という期間を想定した段階分けです。期間が4ヶ月に近い場合はフェーズ5・6を圧縮して並行させ、6ヶ月以上あるならフェーズ2・3を長めに取ってください。「何ヶ月目か」より「どの段階の課題を今やっているか」を意識するのが大切です。

  1. 1

    冒頭の6小節を作り込む 目安: 1ヶ月目

    チェロは「最初の音」から責任が発生します。そこから始めてください。

    • m.1–6 の循環主題(d–cis–f)を最優先で仕上げる。3音だけをチューナーで毎日確認(cis は低めに取りすぎない)。p での発音は「置き弓スタート」——弓を弦に置いてから動かす——に統一する。
    • 音部記号が変わる小節の直前に、鉛筆で縦線と「テノール」「ヘ音」を大書きする。第1楽章の4区間、とくに m.65 と m.321 は小節の途中で変わります。
    • 第3楽章の加線3〜4本の箇所に、鉛筆でテノール記号を書き足す。m.201–202 / m.263–267 / m.421–426。この版の第3楽章は全編ヘ音記号なので、この一手間で読譜負荷が半減します。
    • 全曲を通して1回、遅いテンポで初見通し。止まらず最後まで、を優先。
    • ニ短調・ヘ短調・ニ長調のスケールとアルペジオを毎日のウォームアップに。変ホ短調(♭6)は親指ポジションで別メニューを組む。
  2. 2

    難所の分解練習 目安: 2ヶ月目

    各楽章の難所を、メトロノームで個別に潰していく段階。

    • 第1楽章: m.63–73 の記号往復は「m.13–20(同じ音型のニ短調版、ヘ音記号のみ)を先に仕上げてから」移ると、音型が既知になって記号だけに集中できます。m.353–358 の♭6は先に音名を書き込んでから。
    • 第2楽章: m.199 の「arco→pizz.→arco」を右手だけ(左手は開放弦)で♩=50から100回。弓を持ったまま人差し指で弾く形を固定する。
    • 第3楽章: m.268–279 の6度重音8分連打は、下声だけ／上声だけを全弓レガートで固めてから重音に。m.171–174 の半音階は運指を完全に確定してから。
    • 持ち替えの時間を確認する。第1楽章 m.226–228 と m.240–242 の3小節休みは、pizz./arco の持ち替えのために確保されています。
  3. 3

    弓の持久力を作る 目安: 3ヶ月目

    チェロの最大の課題は「弓が最後まで持つか」です。

    • 第1楽章 m.417–434(18小節の ff 8分音符)を通しで。まず右手だけ(開放弦A・D)で弓順とリズムを ff で通し、弓幅の上限を決め打ちする——ff だからと元弓まで使うと確実に足りません。中弓の1/3幅で密度を出す方向で設計。
    • 60→76→88→100→本番テンポと段階を踏み、各段階で必ず m.417 から通す(部分練習だけでは持久力が付きません)。
    • 第3楽章 m.350–403 の54小節スラーは弓の配分表を作る。S(m.398)で ff になるので m.395 までに弓元に戻しておく。
    • 本番に近いテンポで通し、崩れた箇所はフェーズ2の分解練習に戻す(往復してよい)。
  4. 4

    パート内合わせ 目安: 4ヶ月目

    セクションで音を揃え、ディヴィジを確定させる段階。

    • div. の上下を確定する。第1楽章 m.21–25 / 69–73 / m.282–286 / m.456、第3楽章 m.145 / 153 / m.203(3声) / 293 / 318 / 330 / 347。m.282–286 は下声が完全な保続音で、動かない分だけ音程が露呈します——耳のよい奏者を下に置く判断もあり得ます。
    • 第3楽章 m.268–279 の6度重音は、トゥッティで実際に div. するかを必ず事前に決める。分けるなら上下どちらかだけを完成させればよくなります。
    • ボウイングの統一。とくに循環主題の付点リズム(m.1 ほか)と、第1楽章 m.417–434 の弓順。
    • 練習記号を区切りにして部分練習できるようにする。Jは欠番(Iの次はK)。
  5. 5

    オーケストラ合わせとスタミナ強化 目安: 5ヶ月目

    全奏の中でのバランスと、全曲を通す体力をつける段階。

    • 主題を弾く6か所(第1楽章 m.1 / 29 / 49 / 77 / 331 / 349)では、ヴィオラ・コントラバスと音色とテンポ感を揃える。m.331 は最強奏での再現で、楽章のクライマックスのひとつです。
    • 歌う場面を遠慮しない。第1楽章 m.100–110 の cantabile dolce、m.389–408 の dolce cantabile、第3楽章 m.7–18 と m.98–120。チェロは意外に歌う場面が多いパートです。
    • キュー音符を実際に聴いて入る練習。第1楽章 m.183–194 はフェルマータ3つで拍が数えられず、Vn.I → Vn.II → Va. のキューが唯一の手がかり。「ヴィオラの2小節が終わったら自分」と体で覚える。
    • 3楽章を止まらずに通す練習を重ね、第3楽章の終結まで体力を持たせる。
  6. 6

    仕上げ・本番直前調整 目安: 6ヶ月目／最終週

    技術的な伸びしろより、再現性とコンディションを整える段階。

    • 新しい練習は増やさず、難所を短時間・高頻度で確認するメンテナンス練習に切り替える。
    • m.1 の1音目だけを、毎日いちばん最初に弾く。本番と同じ「冷えた状態」で音程と音色が出せるか——これがこの曲のチェロにとって最後まで残る課題です。
    • ゲネプロで指揮者を見る余裕(目線配分)が確保できているか確認する。とくに第3楽章 m.203–227 のフェルマータ地帯。
    • 楽器・弓・弱音器・松脂など本番当日の道具一式を、直前リハーサルで実際に使っておく。

第1楽章 — Lento / Allegro non troppo

ニ短調 / 4-4 ⇄ 2-2 / 全521小節
練習記号 A〜V(Jは欠番・全21個)

この楽章のチェロには、全曲でいちばん重い責任があります——m.1 の1拍目、循環主題を最初に鳴らすのがチェロだからです。パート譜の冒頭に休符ではなく実音(d–cis–f、付点4分+8分+4分)が書かれていることが、それを裏づけています。この主題を6回にわたって実音で弾くのがチェロの役割で、他のどのパートより多い回数です。技術的な山は別のところにあります——m.417 から18小節ノンストップの8分音符と、♭6の調号で加線3〜4本を読む m.349。そして音部記号がヘ音とテノールを4回往復します。

音部記号は変わりますが、実音でテノール記号を読むのは4区間だけです

チェロ譜にはヘ音・テノール・ト音・アルトの4種類が現れますが、ト音記号とアルト記号はすべてキュー音符用で、チェロは弾きません(m.191–192＝Vn.I/II、m.193–194＝Va.、m.307–308＝Vn.I、m.469–472＝Kl.I)。

MUSIC THEORY BRIDGE

お手元の音楽理論資料との橋渡し

お手元の理論資料(「最短ルートで学ぶ音楽理論の基礎の基礎」)は、スケール・度数・ダイアトニックコード・進行というポップス寄りの基礎体系です。フランクの和声はこの基礎の延長線上にありながら、意図的にそこから「はみ出す」ことで独特の緊張感を作っています。実際の練習で役立つ橋渡しを4点にまとめます。

持続和音では「自分が何度の音か」を意識する

チェロは和声の低音基盤として長い音を保持する場面が多く、第3楽章 m.350–403 の54小節におよぶ2分音符スラーはその極端な例です。資料の「度数」の考え方(長3度・短3度・完全5度…)で、自分の音が根音から見て3度なのか5度なのかを意識すると、単なる「ハモり」ではなく機能的なチューニングができます。長3度は理論値よりわずかに低め、短3度はわずかに高めに取ると和声が澄みます。

フランクの和声は「ダイアトニックの外側」を多用する

資料にある「スケール上で使える和音(Ⅰ・Ⅱm・Ⅲm・Ⅳ・Ⅴ・Ⅵm・Ⅶdim)」はポップスの基本ですが、フランクはⅦdim(減7の和音)や半音による転調を頻繁に使います。終楽章 m.162–186 の25小節にわたる半音階的な8分音符などは、まさに「ダイアトニックを外れ続ける」書法。こうした箇所の音程は、機能和声のロジックではなく「隣の音との半音／全音関係」を頼りにした方が安全です。

循環形式 = 主題の「移調・変容」

資料の「キーチェンジ(全ての音を同じ半音数だけズラす)」の考え方は、循環主題がニ短調のLentoから始まり、終楽章でニ長調へと移調・変容していく様子を理解する助けになります。同じ主題が違う調・速度で出てきたときに「これはあの主題の変形だ」と気づけるようになると、暗譜的な安心感が格段に上がります。終楽章では調号が2度切り替わる(♯2→♯5→♯2)ことも、この変容の道筋を示す手がかりです。

和声語法の「タイプ」を意識する — フランクの"breaking points"論

音楽学者ニコラ・コマトヴィッチの論文「Franck's Breaking Points」は、フランクの和声語法を大きく3タイプ(Type 1=初期の素朴なディアトニック和声、Type 1A=モーダルな要素を含む変種、Type 2=半音階的だが機能和声の骨格はまだ残る円熟期の基本語法、Type 3=機能和声そのものが崩壊し調性判定が困難な晩年のオルガン曲)に整理し、同じ曲の中でもこれらのタイプが急に切り替わる瞬間があると指摘しています。この交響曲では第1・第3楽章がほぼType 2である一方、第2楽章は両端の楽章と比べて和声的にずっと平明だと論文は述べています——「第2楽章は親しみやすい」という肌感覚を、和声語法の面から裏付ける知見です。チェロは和声の低音基盤としてこの切り替えを根音から支える立場にあるので、いま支えているのが半音階的な緊張なのか、素朴で安定した和声なのかを意識すると、音程の作り方(半音階部分は隣接音との関係を優先、機能和声部分は根音基準の度数を優先)を自然に切り替えられます。

なお、同論文の譜例(第3楽章 mm.19–22、ピアノ編曲譜)の説明は、要約版と同じ著者の詳細論文(Komatović, "Evolution Through Synchronicity?", 2022)との間で食い違いがあります——要約版は「表面上は嬰ヘ長調でありながらロ(B)を中心としたミクソリディア旋法への小旅行」、詳細版は「嬰ヘ短調の和音が下属和音の第3音を上げて長和音化し、一時的に嬰系のドリア旋法へ転じる」とし、旋法の種類も調性も一致していません。演奏の指針というより、専門家の間でも解釈が割れる複雑な書法であることを示す背景知識として捉えてください。

GLOSSARY

用語集 — パート譜とこのロードマップに登場する用語

パート譜に実際に印刷されている指示と、このロードマップ中で使った専門用語を、演奏上の意味とともにまとめました。

テンポ・曲想

Lento

「ゆっくりと」。第1楽章冒頭や循環主題が静かに回帰する場面で使われる、この曲の「原点」の速度。

Allegro non troppo

「快速に、ただし度を越さずに」。第1・第3楽章の基本テンポ。「速いが走りすぎない」という抑制が求められる。

Allegretto

「やや快速に」。第2楽章の基本テンポ。Allegroよりやや控えめな快活さ。

Tempo I.

「最初のテンポで」。テンポが大きく動いたあと、楽章冒頭の速度に戻る指示。第3楽章 m.228 に登場する。

Più lento

「より遅く」。フェルマータや静寂部の直前など、テンポが一段緩む箇所に登場する。

a tempo

「もとの速さに戻って」。テンポの伸縮のあとに元のテンポへ復帰する指示。

rallentando (rall.) / poco a poco rall.

「だんだん遅く」／「少しずつ、だんだん遅く」。第3楽章 m.341 の poco a poco rall. は、5小節の休符と重なるため特に注意が要る。

sostenuto / molto sostenuto

「音を十分に保って」／「たっぷりと保って」。音価いっぱいまで途切れさせずに保持するニュアンス。

très long

フランス語で「非常に長く」。第3楽章 m.226–227 のフェルマータに付され、楽章最大の「間」を作る。

Les temps ont la même valeur

フランス語で「拍の長さは同じ」。拍子が変わっても1拍の実時間は変わらないことを示す指示。第3楽章の4か所の拍子変換にすべて付いている。

cantabile / dolce / espressivo

「歌うように」／「甘く柔らかに」／「表情豊かに」。いずれも音量ではなく、フレーズの歌わせ方を指定する曲想語。

sempre〜

「常に〜」。既存の指示をそのまま継続・強調する(sempre ff=ずっと ff のまま、など)。

強弱記号

pp / ppp

「非常に弱く」／「極めて弱く」。この曲では ppp が頻出し、ディヴィジや重音と組み合わさるため単に小さく弾くだけでは足りない。

f / ff

「強く」／「非常に強く」。段階が上がるほど、音量以上に弓の重心とスピードのコントロールが要求される。

cresc. / dim.

crescendo=「だんだん強く」、diminuendo=「だんだん弱く」。molto cresc.は「大きくクレッシェンド」。

sf / sfz (sforzando)

「その音だけ特に強く」。前後の強弱の流れとは別に、単発でアクセントのように打ち込む指示。

marcato ( ^ )

「はっきりと際立たせて」。音符の上の山形記号。一音一音の輪郭を明確に打ち込む。

奏法・技術用語

pizzicato (pizz.) / arco

pizzicato=弓を使わず指で弦をはじく奏法。arco=通常の弓奏に戻る指示。第2楽章はこの切替が頻発する。

divisi (div.) / unisono (unis.)

div.=パート内で複数のグループに分かれて別々の音を弾く指定。unis.=全員が同じ音に戻る指定。誰が上声・下声を弾くかを事前に決めておく必要がある。

double corde

フランス語で「重音」。ディヴィジとは異なり、奏者ひとりひとりが2音を同時に鳴らす指定。第3楽章 m.360 に登場。勝手に分けると和音が痩せる。

4e corde(G線指定)

フランス語で「第4弦」。最低音のG線だけを使って弾く指定。ポジション移動が増える代わりに、暗く太い独特の音色が得られる。第3楽章 m.330 に登場。

トレモロ (trem.)

符尾に斜線を付けて示す、同じ音を細かく速く反復する奏法。第3楽章の刻みの大半がこれ。斜線の本数で細分の単位が決まる。

弱音器 (con sordino / senza sordino)

駒に取り付けて音色をまろやかに変える器具(ミュート)。con=装着、senza=解除。第2楽章で着脱が頻発する。

ペダル音(保続音)

和声が変化していく間、同じ音を長く保持し続ける低音・内声のこと。第3楽章 m.228以降の半音下行する全音符群が典型。

détaché / legato / スタッカート

détaché=1音ごとに弓を返す奏法。legato=複数音を1弓で滑らかにつなぐ。スタッカート=音を短く切る。ボウイング統一の際に区別が問題になる。

三連符

1拍を3等分して弾くリズム単位。第3楽章 m.257–267 では4分音符の3連符が重音で連続し、この曲有数の難所を作る。

プルト

2人1組で1つの譜面台を共有する単位。ディヴィジの割り振りは通常このプルト単位(前プルト＝上声／後プルト＝下声)で決める。

形式・構造用語

ソナタ形式

提示部・展開部・再現部からなる、古典派〜ロマン派の楽章で最も一般的な大規模構成。第1楽章がこれにあたる。

提示部 / 展開部 / 再現部 / コーダ

ソナタ形式を構成する各部分。提示部=主題の初出、展開部=主題の分裂・変容、再現部=主題の回帰、コーダ=曲を締めくくる結尾部。

循環形式

冒頭で提示される主題(モットー)が姿を変えながら全楽章を貫いて回帰する構成。この曲全体を貫く最重要のキーワード。

練習記号(リハーサルレター)

スコアとパート譜に印刷された太字の大文字(A, B, C…)。合奏で指揮者が最も頻繁に使う箇所指示の単位。慣例として I の次は J を飛ばして K になる(I と J の混同を避けるため)。

RECOMMENDED RECORDINGS

おすすめ音源(YouTube)

「名盤かどうか」ではなく、チェロの練習に何の役に立つかで並べました。内声は録音によって聴こえ方が最も変わるパートです。刻みが和音の一部として溶けている演奏と、輪郭が立って聴こえる演奏を弾き比べておくと、合奏で「どちらを求められているか」を判断しやすくなります。掲載した動画はすべて2026年8月22日時点で再生可能なことを確認済みです。

  1. 譜読み用・最優先

    ディミトリ・ミトロプーロス指揮 — 総譜スクロール付き(全3楽章)

    画面に総譜が流れる形式の動画で、3つの楽章がそれぞれ別動画に分かれています。チェロが「いま全体のどこにいるか」を目で確認しながら聴けるため、譜読み段階ではこれが最も実用的です。自分のパートが休んでいる長い小節で他パートが何をしているかを確認する用途にも使えます。ただし歴史的録音のため音質は現代のものに劣ります。 使い方: フェーズ1で全曲の地図を作るとき、そして長休符の前後で「何を聴いて入るか」を決めるときに。

    第1楽章 ／ 第2楽章 ／ 第3楽章

  2. 基準となる1枚

    ピエール・モントゥー指揮 シカゴ交響楽団(1961)

    この曲の基準盤として長く挙げられてきた演奏です。モントゥーは生涯にわたってこの曲を最も多く指揮した指揮者の一人とされ、批評でも「力任せではなく響きの充実で押す」点が評価されています。テンポ設計の基準として、まずこれを体に入れておくと他の演奏の個性が分かります。 使い方: フェーズ1〜2で、自分の練習テンポの目標値を決める基準に。

    YouTubeで聴く

  3. 映像・フランスのオーケストラ

    ルイ・ラングレ指揮 パリ管弦楽団

    演奏風景の映像付きです。チェロの弓の位置・弓幅・ディヴィジの座り方が実際に見えるのが最大の利点。第3楽章 m.300以降の16分音符を、プロがどのくらいの弓幅で弾いているかを目で確認できます。フランスのオーケストラらしい明るめの音色も、この曲の管弦楽法を理解する助けになります。 使い方: フェーズ2で弓の使い方を決めるとき、音ではなく映像を見る資料として。

    YouTubeで観る

  4. 作曲当時の響き

    フランソワ=グザヴィエ・ロト指揮 レ・シエクル(ピリオド楽器)

    時代ごとに楽器を使い分けるオーケストラによる演奏で、1888年当時のフランスの楽器・奏法に近い響きが聴けます。ガット弦寄りの弦の音色、ヴィブラートの少なさ、コルネットを含む金管の音色——「フランクの管弦楽法が分厚い」という一般的な評価が、実は現代楽器での演奏による面もあることが分かります。内声の刻みが埋もれずに聴こえるのも特徴です。 使い方: フェーズ3以降、自分の刻みが「和音に溶ける」べきか「輪郭が立つ」べきかを考える材料に。

    YouTubeで観る(DW Classical Music 公式)

  5. 映像・現代の解釈

    マルク・ミンコフスキ指揮 フランクフルト放送交響楽団

    放送局の公式チャンネルによる高音質の映像。ピリオド演奏の出身であるミンコフスキが現代オーケストラを振ると何が変わるか、という点でロト盤との比較が面白い1本です。カメラが弦楽セクションを抜く場面も多く、ディヴィジやトレモロの実際の処理を確認できます。 使い方: フェーズ4のパート内合わせの前に、ディヴィジの配分イメージを掴む資料として。

    YouTubeで観る(hr-Sinfonieorchester 公式)

  6. 映像・もう1つの比較対象

    マルタイン・ダンディヴェル指揮 WDR交響楽団

    こちらも放送局公式の映像。若い指揮者による近年の演奏で、テンポや強弱の設計が上記の演奏とどう違うかを比べられます。解釈の幅を知っておくと、指揮者から自分の想定と違う指示が来たときに戸惑わずに済みます。 使い方: フェーズ5、オーケストラ合わせでテンポの伸縮に対応する練習の下準備に。

音部記号が変わる4区間に印が入っている。とくに m.65 と m.321 は小節の途中で変わる——直前に縦線と記号名を大書きしてある。

各楽章の難所(第1楽章7・第2楽章5・第3楽章7＝計19箇所)を、単独で止まらずに弾ける。

第1楽章 m.417–434(18小節の ff 8分音符)を、弓を持たせて弾き切れる。弓幅の上限が決まっていて、m.417 から通しで練習してある。

第2楽章の pizz.⇄arco 20か所を本番のテンポで切り替えられる。とくに m.199 の「arco→pizz.→arco」(各0.5拍)。「弓を持ったまま人差し指で撥弦する」方式に統一してある。

弱音器の着脱4か所(m.94 装着 / m.133 解除 / m.174 装着 / m.238 解除＝猶予約6拍、直後が f の2声)を、本番で使う器具で音を立てずに行える。

第3楽章 m.268–279 の6度重音を、div. するかどうか決めてある。全員重音だと音程の濁りと消耗が大きい箇所です。

キュー音符を耳で覚えている。第1楽章 m.183–194 はフェルマータ3つで拍が数えられず、Vn.I → Vn.II → Va. のキューが唯一の手がかり——「ヴィオラの2小節が終わったら自分」。他に m.307–308(Vn. I)、m.469–472(Kl. I)。第2・第3楽章にはキュー音符が1つもありません。

第3楽章 m.339–345 の7小節休みを、指揮を見て数えられる。poco a poco rall. の最中でキューもないため、拍では数えられません。
