BACKGROUND

教会オルガニストが66歳で書いた、最初で最後の交響曲

セザール・フランク(1822–1890)はベルギー・リエージュ生まれ。パリ音楽院でピアノを学んだのち、生涯の大半を教会オルガニストとして過ごしました。1858年にサント=クロチルド教会の主任オルガニストに就任し、1872年からはパリ音楽院オルガン科教授も務めています。弟子にはヴァンサン・ダンディ、エルネスト・ショーソン、アンリ・デュパルク、ルイ・ヴィエルヌ、シャルル・トゥルヌミール、ギヨーム・ルクーら——後に「フランキスト」と呼ばれる一群がいました。代表作(この交響曲・ヴァイオリンソナタ・弦楽四重奏曲)はいずれも驚くほど晩年に集中して生まれています。

交響曲の作曲は1887年の夏に始まり、総譜が完成したのは1888年8月22日、フランク66歳のときでした。献呈されたのは、ワーグナーの楽劇研究を勧めた弟子デュパルクです。初演の道のりは平坦ではなく、指揮者シャルル・ラムルーには一度断られています。結局1889年2月17日、パリ音楽院のコンセール・ソシエテで、ジュール・ガルサン指揮により初演されました。フランクはその翌1890年、乗合馬車との接触事故をきっかけに体調を崩し、この世を去ります。

初演の評価は真っ二つでした。『フィガロ』紙は「きわめて重要な作品」としつつ「あまりに濃密で緊密なため、一度聴いただけではその全貌を掴みきれない」と書き、熱狂と冷淡さの同居を伝えています。批評家カミーユ・ベレーグは「潤いも魅力もない、乾いてくすんだ音楽」と切り捨て、『ル・メネストレル』紙は「陰鬱で仰々しく、語ることが少ない」と評しました。作曲家グノーに至っては「独断にまで押し進められた無能の断言」と言い放ったと伝えられます。とりわけ集中砲火を浴びたのが、第2楽章で主題を歌うコーラングレ(イングリッシュホルン)でした——音楽院の同僚が「交響曲にコーラングレを使うなど、誰が聞いたことがあるか」と詰め寄った逸話は有名です。普仏戦争(1870–71)の敗戦後、フランス音楽界にはナショナリズムが渦巻いており、ワーグナーとリストの影響を隠さないフランクの書法は「裏切り」とすら見なされました。

それでも作曲者自身は動じませんでした。弟子たちが伝えるところによれば、フランクは初演のホールを出るとき「実によく鳴ったじゃないか」と満足げに語ったといいます。作品が広く受け入れられたのは、1893年に当のラムルーがようやく取り上げてからのこと。以後この曲は、フランスの交響曲としては例外的な頻度で演奏される「近代の古典」となりました。

フランク自身は3つの楽章にそれぞれ性格づけを与えています——第1楽章は「力強く、そして温かく」、第2楽章は「甘美で、もの悲しく」、終楽章は「輝かしく、光を放つように」。第2楽章が緩徐楽章とスケルツォを1つに融合した特異な構造なのは、4楽章制を3楽章に圧縮した結果です。そして全体を貫くのが循環形式(cyclic form)——冒頭に置かれた短い動機が、姿を変えながら全楽章に回帰する構成原理です。ベートーヴェンの第9交響曲を先例とし、直接には前年に成功したサン=サーンス《オルガン付き》交響曲(1886)からの示唆があったとされます。

今回参照した楽譜について — なぜ小節番号が旧版と違うのか

この交響曲の自筆総譜は1935年、シャトーの火災で焼失しています。そのため現行の校訂譜は、フランク生前に出版された初版譜と、作曲者自身による4手ピアノ編曲を典拠に復元されたものです。今回参照したブライトコプフ&ヘルテル社のウアテクスト版(Peter Jost 校訂, 1999年 / Orchester-Bibliothek 5328)もこの系譜にあります。
このパート譜には各段の頭に小節番号が、そして練習記号(A, B, C…)が明記されています。本ロードマップの小節番号・練習記号はすべてこの版の印刷値です。IMSLPで入手できるパブリックドメインの旧パート譜とは番号がずれる箇所があるため、他パートの奏者と場所を確認し合うときは「どの版か」を先に揃えてください。

OVERVIEW

なぜこの曲のヴィオラは難しいのか

ヴィオラには2つのまったく違う難しさが同時にかかります。ひとつは読譜——第1楽章だけで音部記号がアルト⇄ト音で22回変わり、しかも m.63 は32分音符の走句の途中、m.337→338 は1小節足らずで往復します。もうひとつは体力配分——第3楽章では m.266 から m.299 まで30小節以上、重音3連符とトレモロがほぼ休みなしで続き、その直後の m.300 が楽章最難の高音走句です。

そして厄介なことに、高音域でもト音記号に変わってくれない箇所があります。第3楽章の m.174–180 や m.300–315 は加線3〜4本をアルト記号のまま読むことになる。加線が3本を超える音には鉛筆で音名を書き込む——この一手間が、この曲では本当に効きます。

一方で、ヴィオラには他パートにはない特権があります。m.1 の1拍目、循環主題を最初に鳴らすのがヴィオラです(チェロ・コントラバスと共に)。パート譜の冒頭に休符ではなく主題が p で書かれていて、両ヴァイオリンはそれを「Va.」のキュー音符として見ている——この楽章の構造的な節目は、毎回ヴィオラが最初に鳴らすことになります。第1楽章で主題を弾く5か所は、すべてそういう場所です。

第2楽章では冒頭からディヴィジのピチカート和音で始まる唯一のパートになり、pizz.⇄arco の持ち替えは17回。うち m.86 と m.124 の2箇所は猶予が半拍しかありません。「弓を持ったまま人差し指で弾く」方式に統一するかどうかを、譜読みの早い段階で決めてしまうのが得策です。

以下の楽章別セクションは、パート譜全14ページ(第1楽章 p.2–7 / 第2楽章 p.8–11 / 第3楽章 p.11–15)を1ページずつ視覚解析し、印刷された小節番号・練習記号・強弱・奏法指示をすべて拾い出したうえで構成しています。

ROADMAP

本番までの6フェーズ

4〜6ヶ月以上という期間を想定した段階分けです。期間が4ヶ月に近い場合はフェーズ5・6を圧縮して並行させ、6ヶ月以上あるならフェーズ2・3を長めに取ってください。「何ヶ月目か」より「どの段階の課題を今やっているか」を意識するのが大切です。

  1. 1

    読譜の下準備 — 音部記号と加線を先に潰す 目安: 1ヶ月目

    ヴィオラだけは、音を出す前にやるべき作業があります。

    • 音部記号が変わる小節に、蛍光ペンで縦線と「G」「C」を大書きする。第1楽章の22か所すべて。とくに m.63(32分走句の途中)と m.337/338(1小節足らずの往復)は1小節前の小節線にも印を。
    • 加線が3本を超える音に、鉛筆で音名を書き込む。第3楽章 m.174–180 と m.300–315 はアルト記号のまま加線3〜4本です。
    • キュー音符専用のト音記号を見分ける。第1楽章 m.95 / 191 / 307 / 469、第2楽章 m.96 / 139 はヴィオラは弾きません。「休」と書き込んでおく。
    • 循環主題を歌えるようにする。m.1 の1拍目から自分が弾く主題です——「長い音→半音下→跳躍上行」。これが全曲の道しるべになります。
    • 全曲を通して1回、遅いテンポで初見通し。止まらず最後まで、を優先。
  2. 2

    難所の分解練習 目安: 2ヶ月目

    各楽章の難所を、メトロノームで個別に潰していく段階。

    • 第1楽章: m.61–64 は「m.62の末尾から m.63 の頭までを2小節だけ切り出して20回」——記号の切り替わりを身体に入れる。m.129–144 の16小節は跳躍の音程ごとに色分けして分類する。
    • 第2楽章: m.86 と m.124 の半拍の持ち替えを単独ドリル化。弓を持ったまま人差し指で弾く形を固定し、♩=60から本番テンポまで。
    • 第3楽章: m.300–317 をすべて4分音符に引き伸ばして音名と運指を確定してから、リズムを戻す。m.88–95 の♯5つ div. は上下両方を1人で弾いて和音を耳に入れる。
    • 弱音器は本番と同じ器具で。第2楽章 m.238 の解除は猶予約4拍で、直後が f → m.246 で ff です。
    • ディヴィジの3音和音(第1楽章 m.171–182 / m.227–238、第3楽章 m.181–186 ほか)は、div. a3 か div.+重音かをパートで決めておく。
  3. 3

    体力配分の設計 目安: 3ヶ月目

    ヴィオラにとって、この曲最大の課題は「最難関まで腕を残せるか」です。

    • 第3楽章 m.266–299 を通しで1回弾く練習を毎日入れる。30小節以上の重音3連符とトレモロを弾いた直後に、m.300 の最難関が来ます。「弾けるか」ではなく「m.300 まで腕を残せるか」が課題です。
    • トレモロは弓の使用幅を1〜2cmに固定し、上腕を脱力して前腕の速い回転だけで作る。メトロノーム無しで30秒×3セットの持久トレーニングを。
    • 第1楽章 m.129–144 と m.418–434 の ff 8分音符16小節×2 も、まず mf で形を作ってから ff を足す。
    • 本番に近いテンポで通し、崩れた箇所はフェーズ2の分解練習に戻す(往復してよい)。
  4. 4

    パート内合わせ — ディヴィジと音程 目安: 4ヶ月目

    ヴィオラは div. が非常に多いパートです。割り振りを確定させる段階。

    • div. の上下を全箇所で確定する。原則は「下声を優先して決める」——フランクの和声は下声が根音・第5音・導音を担うことが多く、下声が正しく鳴れば上声は耳で合わせられます。
    • 3音和音の箇所(第1楽章 m.171–182 / m.227–238、第3楽章 m.181–186 / 206 / 269 / 298–299 / 406–413)はdiv. a3 か div.+重音かを指揮者・パートリーダーに確認。
    • 「unis. だが2音」の箇所に注意。第3楽章 m.31 と m.292 は全員が重音で弾く指示で、div. ではありません。
    • トレモロ区間(第1楽章 m.21–28 / 69–76 / 227–238)は音量より音色が目的なので、上下とも弓を短く・弓速一定にそろえる。
    • 練習記号を区切りにして部分練習できるようにする。Jは欠番(Iの次はK)。
  5. 5

    オーケストラ合わせとスタミナ強化 目安: 5ヶ月目

    全奏の中でのバランスと、全曲を通す体力をつける段階。

    • 主題を弾く5か所(第1楽章 m.1 / 29 / 49 / 77 / 349)では、自分が構造の節目を告げているという意識で。チェロ・コントラバスと音色を揃える。
    • 第1楽章 m.215–224 の "f ma cantando" は、ヴィオラが表に出る唯一の長い旋律区間です。ここは遠慮せずに歌う。
    • キュー音符を実際に自分のヴィオラで弾いてみる。第1楽章 m.307–316 の「Vn. I」キューは、19小節の休みから復帰するための命綱です(音は違っても輪郭が分かります)。
    • 3楽章を止まらずに通す練習を重ね、第3楽章の終結まで体力を持たせる。
  6. 6

    仕上げ・本番直前調整 目安: 6ヶ月目／最終週

    技術的な伸びしろより、再現性とコンディションを整える段階。

    • 新しい練習は増やさず、難所を短時間・高頻度で確認するメンテナンス練習に切り替える。
    • 音部記号の切替だけを通しで確認する日を1日作る。22か所すべてを、音を出さずに譜面を追うだけでよい。
    • ゲネプロで指揮者を見る余裕(目線配分)が確保できているか確認する。とくにフェルマータの多い区間。
    • 楽器・弓・弱音器・松脂など本番当日の道具一式を、直前リハーサルで実際に使っておく。
MOVEMENT I

第1楽章 — Lento / Allegro non troppo

ニ短調 / 4-4 ⇄ 2-2 / 全521小節
練習記号 A〜V(Jは欠番・全21個)

ヴィオラもチェロと並んで、m.1 の1拍目から循環主題を実音で弾く「起点」のパートです——パート譜の冒頭に休符ではなく主題が p で書かれていることが、それを裏づけています。しかも循環主題を弾く5か所は、すべて楽章の構造的な節目(Lentoの提示とそのAllegro版)。この楽章の切れ目は、毎回ヴィオラが最初に鳴らすことになります。
技術的な負荷は別のところに集中しています——音部記号がアルト⇄ト音で22回変わり、うち m.337 と m.338 は小節の途中。そして ff の8分音符が16小節連続する区間が2度(m.129 / m.418)あります。

音部記号が22回変わります — この楽章の最大の読譜負荷

基本はアルト記号ですが、高音域ではト音記号に切り替わります。うち4回はキュー音符専用でヴィオラは弾きません(m.95＝Fl.I/II、m.191＝Vn.I/II、m.307＝Vn.I、m.469＝Kl.I)。
とくに危険なのが2箇所です。m.63——32分音符の半音階走句の途中でト音記号に変わり、走句の中で記号が変わったように錯覚します。そして m.337 でト音記号 → m.338 でアルト記号という、1小節足らずの極端に短い切替。
切替小節の頭に蛍光ペンで縦線と「G」「C」を大書きし、m.63 と m.337/338 は1小節前の小節線にも印を入れておくことを強く勧めます。

    m.113–124(G〜H) — pizz.⇄arco の高速交替地帯 12小節の間に4回持ち替えます。とくに m.123 の3拍目に pizz. を弾いた直後、8分休符ひとつ(半拍)で m.124 の1拍目を arco の div. 和音で弾く箇所は第1位と同格。音型が「8分音符+8分休符」の点描なので、pizz. と arco で音の立ち上がりの性格が変わるとセクション内で音がバラけます。ヴィオラは音の減衰が速く、pizz. の余韻が短いためテンポが前のめりになりやすい。 対策: ①持ち替え位置を鉛筆で丸で囲み、直前の休符に「持」と書き込む——視覚化しないと本番で必ず落とします。②pizz. は弓を持ったまま人差し指で統一し、弓を膝に置く動作は絶対にしない。③arco 側は必ず同じ弓の場所(元から1/3)でダウンから始めると決め、持ち替え後に弓の位置を探さないようにする。④3段階法——m.113–124を「pizz.部分だけ／arco部分だけ」に分けて通す → 持ち替えなしで全部 arco で通してテンポと音程を固める → 最後に持ち替えを乗せる。

    m.49–86(C〜E) — 38小節に及ぶ連続16分音符 ほぼ休みなく16分音符が続き、pp → cresc. → f → dim. → pp と大きく振れます。臨時記号が半音階的に密で、♭2の調号なのに実質は転調の連続。ヴィオラは内声なので、この音型は「聴こえないが外れると全体が濁る」典型です。3〜4音ずつの不規則なスラー区切りに従うと弓の配分が崩れやすく、E以降の f で弓が足りなくなります。最高で第3ポジションまで上がるため、移弦とポジション移動が16分音符の中で同時発生します。 対策: ①リズム変奏(付点／逆付点／3連ずつ)で各音の左手到達点を確定させる。②スラーを全部外して détaché で音程だけさらってからスラーを戻す。③f の区間(m.78–82)は弓を「元寄り・広め」、pp の区間(m.83–86)は「中央・狭く」と弓の場所を先に決めて書き込む。④開放弦を使わない運指に統一——弱音器なしのこの区間で開放弦が混ざると音色が飛び出ます。⑤拍頭の音(各拍1つ目の16分)だけを抜き出して和声の骨格を確認し、チェロ／ファゴットのバスと合わせる意識を持つ。

MUSIC THEORY BRIDGE

お手元の音楽理論資料との橋渡し

お手元の理論資料(「最短ルートで学ぶ音楽理論の基礎の基礎」)は、スケール・度数・ダイアトニックコード・進行というポップス寄りの基礎体系です。フランクの和声はこの基礎の延長線上にありながら、意図的にそこから「はみ出す」ことで独特の緊張感を作っています。実際の練習で役立つ橋渡しを4点にまとめます。

持続和音では「自分が何度の音か」を意識する

ヴィオラは長い和音を保持する場面が非常に多く、第1楽章 m.171–182・m.227–238 の3音和音を12小節保つトレモロはその典型です。資料の「度数」の考え方(長3度・短3度・完全5度…)で、自分の音が根音から見て3度なのか5度なのかを意識すると、単なる「ハモり」ではなく機能的なチューニングができます。長3度は理論値よりわずかに低め、短3度はわずかに高めに取ると和声が澄みます。

フランクの和声は「ダイアトニックの外側」を多用する

資料にある「スケール上で使える和音(Ⅰ・Ⅱm・Ⅲm・Ⅳ・Ⅴ・Ⅵm・Ⅶdim)」はポップスの基本ですが、フランクはⅦdim(減7の和音)や半音による転調を頻繁に使います。終楽章 m.162–186 の25小節にわたる半音階的な8分音符などは、まさに「ダイアトニックを外れ続ける」書法。こうした箇所の音程は、機能和声のロジックではなく「隣の音との半音／全音関係」を頼りにした方が安全です。

循環形式 = 主題の「移調・変容」

資料の「キーチェンジ(全ての音を同じ半音数だけズラす)」の考え方は、循環主題がニ短調のLentoから始まり、終楽章でニ長調へと移調・変容していく様子を理解する助けになります。同じ主題が違う調・速度で出てきたときに「これはあの主題の変形だ」と気づけるようになると、暗譜的な安心感が格段に上がります。終楽章では調号が2度切り替わる(♯2→♯5→♯2)ことも、この変容の道筋を示す手がかりです。

和声語法の「タイプ」を意識する — フランクの"breaking points"論

音楽学者ニコラ・コマトヴィッチの論文「Franck's Breaking Points」は、フランクの和声語法を大きく3タイプ(Type 1=初期の素朴なディアトニック和声、Type 1A=モーダルな要素を含む変種、Type 2=半音階的だが機能和声の骨格はまだ残る円熟期の基本語法、Type 3=機能和声そのものが崩壊し調性判定が困難な晩年のオルガン曲)に整理し、同じ曲の中でもこれらのタイプが急に切り替わる瞬間があると指摘しています。この交響曲では第1・第3楽章がほぼType 2である一方、第2楽章は両端の楽章と比べて和声的にずっと平明だと論文は述べています——「第2楽章は親しみやすい」という肌感覚を、和声語法の面から裏付ける知見です。ヴィオラは内声としてこの切り替えを和声の中核で支える立場にあるので、いま支えているのが半音階的な緊張なのか、素朴で安定した和声なのかを意識すると、音程の作り方(半音階部分は隣接音との関係を優先、機能和声部分は根音基準の度数を優先)を自然に切り替えられます。

なお、同論文の譜例(第3楽章 mm.19–22、ピアノ編曲譜)の説明は、要約版と同じ著者の詳細論文(Komatović, "Evolution Through Synchronicity?", 2022)との間で食い違いがあります——要約版は「表面上は嬰ヘ長調でありながらロ(B)を中心としたミクソリディア旋法への小旅行」、詳細版は「嬰ヘ短調の和音が下属和音の第3音を上げて長和音化し、一時的に嬰系のドリア旋法へ転じる」とし、旋法の種類も調性も一致していません。演奏の指針というより、専門家の間でも解釈が割れる複雑な書法であることを示す背景知識として捉えてください。

用語集 — パート譜とこのロードマップに登場する用語

パート譜に実際に印刷されている指示と、このロードマップ中で使った専門用語を、演奏上の意味とともにまとめました。

テンポ・曲想

Lento

「ゆっくりと」。第1楽章冒頭や循環主題が静かに回帰する場面で使われる、この曲の「原点」の速度。

Allegro non troppo

「快速に、ただし度を越さずに」。第1・第3楽章の基本テンポ。「速いが走りすぎない」という抑制が求められる。

Allegretto

「やや快速に」。第2楽章の基本テンポ。Allegroよりやや控えめな快活さ。

Tempo I.

「最初のテンポで」。テンポが大きく動いたあと、楽章冒頭の速度に戻る指示。第3楽章 m.228 に登場する。

Più lento

「より遅く」。フェルマータや静寂部の直前など、テンポが一段緩む箇所に登場する。

a tempo

「もとの速さに戻って」。テンポの伸縮のあとに元のテンポへ復帰する指示。

rallentando (rall.) / poco a poco rall.

「だんだん遅く」／「少しずつ、だんだん遅く」。第3楽章 m.341 の poco a poco rall. は、5小節の休符と重なるため特に注意が要る。

sostenuto / molto sostenuto

「音を十分に保って」／「たっぷりと保って」。音価いっぱいまで途切れさせずに保持するニュアンス。

très long

フランス語で「非常に長く」。第3楽章 m.226–227 のフェルマータに付され、楽章最大の「間」を作る。

Les temps ont la même valeur

フランス語で「拍の長さは同じ」。拍子が変わっても1拍の実時間は変わらないことを示す指示。第3楽章の4か所の拍子変換にすべて付いている。

cantabile / dolce / espressivo

「歌うように」／「甘く柔らかに」／「表情豊かに」。いずれも音量ではなく、フレーズの歌わせ方を指定する曲想語。

sempre〜

「常に〜」。既存の指示をそのまま継続・強調する(sempre ff=ずっと ff のまま、など)。

強弱記号

pp / ppp

「非常に弱く」／「極めて弱く」。この曲では ppp が頻出し、ディヴィジや重音と組み合わさるため単に小さく弾くだけでは足りない。

f / ff

「強く」／「非常に強く」。段階が上がるほど、音量以上に弓の重心とスピードのコントロールが要求される。

cresc. / dim.

crescendo=「だんだん強く」、diminuendo=「だんだん弱く」。molto cresc.は「大きくクレッシェンド」。

sf / sfz (sforzando)

「その音だけ特に強く」。前後の強弱の流れとは別に、単発でアクセントのように打ち込む指示。

marcato ( ^ )

「はっきりと際立たせて」。音符の上の山形記号。一音一音の輪郭を明確に打ち込む。

奏法・技術用語

pizzicato (pizz.) / arco

pizzicato=弓を使わず指で弦をはじく奏法。arco=通常の弓奏に戻る指示。第2楽章はこの切替が頻発する。

divisi (div.) / unisono (unis.)

div.=パート内で複数のグループに分かれて別々の音を弾く指定。unis.=全員が同じ音に戻る指定。誰が上声・下声を弾くかを事前に決めておく必要がある。

double corde

フランス語で「重音」。ディヴィジとは異なり、奏者ひとりひとりが2音を同時に鳴らす指定。第3楽章 m.360 に登場。勝手に分けると和音が痩せる。

4e corde(G線指定)

フランス語で「第4弦」。最低音のG線だけを使って弾く指定。ポジション移動が増える代わりに、暗く太い独特の音色が得られる。第3楽章 m.330 に登場。

トレモロ (trem.)

符尾に斜線を付けて示す、同じ音を細かく速く反復する奏法。第3楽章の刻みの大半がこれ。斜線の本数で細分の単位が決まる。

弱音器 (con sordino / senza sordino)

駒に取り付けて音色をまろやかに変える器具(ミュート)。con=装着、senza=解除。第2楽章で着脱が頻発する。

ペダル音(保続音)

和声が変化していく間、同じ音を長く保持し続ける低音・内声のこと。第3楽章 m.228以降の半音下行する全音符群が典型。

détaché / legato / スタッカート

détaché=1音ごとに弓を返す奏法。legato=複数音を1弓で滑らかにつなぐ。スタッカート=音を短く切る。ボウイング統一の際に区別が問題になる。

三連符

1拍を3等分して弾くリズム単位。第3楽章 m.257–267 では4分音符の3連符が重音で連続し、この曲有数の難所を作る。

プルト

2人1組で1つの譜面台を共有する単位。ディヴィジの割り振りは通常このプルト単位(前プルト＝上声／後プルト＝下声)で決める。

形式・構造用語

ソナタ形式

提示部・展開部・再現部からなる、古典派〜ロマン派の楽章で最も一般的な大規模構成。第1楽章がこれにあたる。

提示部 / 展開部 / 再現部 / コーダ

ソナタ形式を構成する各部分。提示部=主題の初出、展開部=主題の分裂・変容、再現部=主題の回帰、コーダ=曲を締めくくる結尾部。

循環形式

冒頭で提示される主題(モットー)が姿を変えながら全楽章を貫いて回帰する構成。この曲全体を貫く最重要のキーワード。

練習記号(リハーサルレター)

スコアとパート譜に印刷された太字の大文字(A, B, C…)。合奏で指揮者が最も頻繁に使う箇所指示の単位。慣例として I の次は J を飛ばして K になる(I と J の混同を避けるため)。
